## [0.2.0] - YYYY-MM-DD

### Action required

- `strict_mode` is no longer read. A configuration that sets it sets `strict` to the same value instead. (ca9d073)

### Features

- The `trim` option drops trailing whitespace from the output. (channel, 48f7e32)

### Bug fixes

- An error raised in a nested call names the position of the call, so a caller finds it. (c14495f)
- Input that is not UTF-8 returns an error instead of a panic. (2eed447)
- An error names the line of the input, as the Java library does. (e88d7ac)

### Performance

- An input used twice is parsed once, so using it again is faster. (032d259)

### Other changes

- The README lists every option with its default. (91f9c51)
